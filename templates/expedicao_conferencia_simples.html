Como funciona

Só o essencial para a equipe operar sem desviar para outro painel.

1. Informe o orçamento

Esse é o identificador principal da conferência.

2. Consulte a NF

Se ela já existir na Consyste, o cliente vem preenchido. Se ainda não existir, o campo do cliente abre para digitação manual.

3. Anexe as fotos

Pelo menos uma imagem é obrigatória para salvar a conferência.

4. Marque como expedido depois

Quando a saída acontecer, atualize o status no histórico.
